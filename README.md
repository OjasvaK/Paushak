## Local setup

Requires Node.js and npm.

```bash
npm install
cp .env.example .env.local   # fill in values as stages need them
npm run dev                  # http://localhost:3000
```

Scripts: `dev`, `build`, `start`, `lint`, `format`, `format:check`.

A full setup and deploy guide comes in Stage 10.
